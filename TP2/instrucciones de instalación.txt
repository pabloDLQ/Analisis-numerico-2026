INSTRUCCIONES PARA CREAR EL ENTORNO VIRTUAL E INSTALAR HERRAMIENTAS (TP2)
PASOS (ejecutar en una terminal):

1. Crear el entorno virtual (llamado "tp2_env"):
   python -m venv tp2_env

2. Activar el entorno virtual:
     tp2_env\Scripts\activate

3. Instalar los paquetes necesarios:
   pip install numpy scipy matplotlib opencv-python scikit-image imageio

Para salir del entorno virtual:
   deactivate
