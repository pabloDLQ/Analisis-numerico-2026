Este archivo explica, paso por paso, qué hace el módulo metodo.py.

Idea general:
- El módulo expone una sola función pública: encontrar_raiz(f, a, b, tol).
- La función recibe una función f que debe evaluarse con tipo="comun" o tipo="derivada".
- El objetivo es devolver una aproximación de la raíz usando una estrategia híbrida.

Paso 1: lectura de la entrada.
- Se recibe la función a estudiar y un intervalo inicial [a, b].
- También se recibe una tolerancia tol para decidir cuándo detener el algoritmo.
- Se usa un máximo de 150 iteraciones.

Paso 2: evaluación inicial.
- Se calculan f(a) y f(b).
- Si alguno de los extremos ya es raíz exacta, se devuelve de inmediato.
- También se guarda la mejor aproximación encontrada hasta el momento.

Paso 3: rama segura con cambio de signo.
- Si f(a) y f(b) tienen signos opuestos, se usa Ridders como base segura.
- En cada iteración se calcula el punto medio del intervalo.
- Con ese valor y con los extremos se construye una nueva aproximación más rápida que la bisección.
- Si la fórmula no puede aplicarse, el método cae al punto medio.
- El intervalo se actualiza con el subintervalo que conserva el cambio de signo.

Paso 4: rama abierta sin cambio de signo.
- Si el intervalo no encierra un cambio de signo, se usa secante como acelerador principal.
- La secante no necesita derivadas y suele avanzar rápido cuando la función se comporta bien.
- Si hace falta, se aplica una sola vez Newton-Raphson como reset puntual del peaje.
- Ese paso con derivada solo se usa antes de llegar a la quinta evaluación común.

Paso 5: control de parada.
- El algoritmo se detiene cuando dos iteraciones consecutivas quedan a distancia menor o igual que tol.
- Si una propuesta sale del intervalo o no es numérica, se reemplaza por una alternativa segura.
- Si no se llega a una convergencia exacta, se devuelve la mejor aproximación acumulada.

Paso 6: salida.
- La función devuelve solo un número flotante.
- Ese número representa la mejor estimación de la raíz encontrada.

Archivos relacionados:
- metodo.py: contiene la implementación principal.
- test_metodo.py: contiene pruebas unitarias simples para verificar el resultado.
